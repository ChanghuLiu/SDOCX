## Full description

Escape your Samsung Notes exports into an open, portable archive.

Notes Escape: SDOCX converts Samsung Notes `.sdocx` files on your Android
device into Markdown and Obsidian-compatible ZIP archives. Select one note,
multiple notes, a folder, or receive `.sdocx` files through Android sharing.

What you can do:

- Convert notes in batches with progress and per-note results.
- Export clean Markdown or Obsidian Rich Markdown.
- Preserve typed text and Unicode, including RTL languages, where recoverable.
- Preserve images and supported media in the archive.
- Preserve handwriting as SVG where the source format is supported.
- Preserve attachments and unknown embedded media as files when possible.
- Optionally include the original `.sdocx` files in the migration ZIP.
- Keep a Markdown and JSON migration report for review.

Everything is processed locally. There is no account, upload, cloud service,
advertising, analytics, or Internet permission. You choose the source files and
the ZIP destination using Android’s file picker.

Important limitations:

- Some Samsung Notes formatting may not convert exactly.
- Rich formatting support varies by Samsung Notes version.
- Complex tables, formulas, proprietary objects, and unknown SDOCX variants may
  be partially converted.
- Original page layout is not guaranteed.
- Locked notes must be unlocked in Samsung Notes before export.

Notes Escape is an independent utility and is not affiliated with, endorsed by,
or sponsored by Samsung.
