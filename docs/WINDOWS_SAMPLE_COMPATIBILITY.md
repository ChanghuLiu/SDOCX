# Samsung Notes for Windows black-box compatibility

This report records a transient interoperability run against the public
`0xA01F3/sdocx_parser` sample names. That repository is GPL-3.0. Its parser
source, fixtures, PDFs, and generated reference files were not copied into
this repository, were not used as code references, and were deleted after the
run. The samples were used only as temporary black-box inputs; they are not
distributed here.

The samples were generated by Samsung Notes for Windows. They are evidence for
the Windows-produced SDOCX shape, not proof of Samsung Notes Android/mobile
compatibility. Format version was `4000` in every sample. The app-version field
was not detectable in this corpus.

## Semantic classification

| feature | result | evidence |
|---|---|---|
| titles and format version | PASS | Internal titles were recovered (`cupcake`, `fire_and_ice`, `flowers`, `mushroom`, `The Raven`, `zombie`); all reported version `4000`. |
| typed text and paragraph order | PASS | All text-bearing samples recovered structured UTF-16 text; `flowers` correctly produced no typed text. |
| bold | PASS | `cupcake` produced a bold Markdown span for the controlled bold paragraph. |
| italic | PASS | `cupcake` produced an italic Markdown span for the controlled italic paragraph. |
| underline | PARTIAL | `cupcake` records were recognized; Clean Markdown intentionally drops underline and Obsidian Rich is the supported semantic-preserving mode. |
| strikethrough | PASS | `cupcake` and `fire_and_ice_F` produced valid `~~...~~` output where the record/state was available. |
| numbered list | PASS | `cupcake` emitted `1.`, `2.`, and `3.` using structured list numbers. |
| bullet list | PASS | `cupcake` and fire-and-ice variants emitted bullet paragraphs from paragraph records. |
| checkbox state | PASS | `cupcake` emitted one unchecked and one checked item; `fire_and_ice_F` emitted four items with two checked. |
| indentation | PASS | `cupcake` preserved two observed indent levels as Markdown indentation. |
| image-object decoding | NOT PRESENT | No Windows sample yielded a decoded `ImageElement`; `mushroom` nevertheless resolved two JPEG registry media entries. |
| media registry/copy-through | PASS | `mushroom` resolved three registry entries, copied original JPEG bytes, and preserved the unknown `.spi` as an attachment. |
| handwriting | PARTIAL | `flowers`, `mushroom`, and `raven` produced valid non-empty SVG output; one malformed mushroom stroke payload was reported and omitted. |
| dark-theme metadata | PASS | `raven` parsed and exported without requiring visual paper/theme reconstruction. |

The generated temporary archives contained `migration-report.md` and
`migration-report.json` for every sample. Their Markdown paths were safe and
the reports distinguished `PARTIAL` from `SUCCESS`.
